# Documentație e-glasul

## Structură

- `product/features/` — feature briefs
- `product/domain/` — domain reviews și surse oficiale
- `architecture/specs/` — specificații tehnice
- `architecture/` — system context, module maps și diagrame
- `decisions/` — ADR-uri
- `project/` — riscuri, întrebări și decizii de proiect

Documentele trebuie versionate împreună cu codul.
